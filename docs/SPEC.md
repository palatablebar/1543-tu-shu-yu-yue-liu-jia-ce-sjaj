# 图书预约留架册数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `notice_lag` | 通知送达延迟 | h | 0–20 |
| `walk_mins` | 取件步行估计 | min | 3–55 |
| `weekday` | 通知星期 | 日 | 0–6 |
| `renewals` | 延期申请 | 次 | 0–4 |
| `waiting_readers` | 后续预约户 | 户 | 0–32 |
| `held_age` | 已留架时间 | h | 10–65 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。已取件时为总留架时长，右截尾时为最后可确认的留架时长，均以小时计。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 短信回执 | `message_lag_minutes` | 发到回执分钟 | 60 | 0 |
| 短信回执 | `walk_seconds` | 到馆步行秒 | 60 | 0 |
| 读者预约 | `iso_weekday` | 周一为1的星期 | 1 | 1 |
| 读者预约 | `extension_tallies` | 延期共计 | 1 | 0 |
| 留架巡查 | `pending_accounts` | 后续读者人数 | 1 | 0 |
| 留架巡查 | `shelf_age_minutes` | 保留架分钟数 | 60 | 0 |

示例见 `sample_data/hold_slips_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[2,40)`、校准 `[42,62)`、回放 `[65,84)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `trip_friction` | 到馆时间成本 | `walk_mins + 2 * notice_lag` |
| `weekend_span` | 周末标记 | `float(weekday >= 4)` |
| `renewal_load` | 当前延期负担 | `renewals * (1+notice_lag/10)` |
| `queue_days` | 预约等待小时积 | `waiting_readers * held_age / 24` |
| `contact_recency` | 通知后已过去 | `max(0,held_age-notice_lag)` |

### Kaplan–Meier 留架尾部估计

用已取件事件与未取件的右截尾时间构造生存曲线，分别保存工作日组与周末组。对已留架时刻右侧的条件曲线积分至 96 小时。

本工作台的独立样本校准方式为剩余留架比例误差。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较训练邻域距离。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 安排复核释放

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `EXTENSION_OPEN` | `renewals >= 3 and held_age < 44` | 延期未处理，保持留架 |
| 2 | `CROWDED_SHELF` | `waiting_readers >= 14 and estimate >= 30` | 优先核实架位 |
| 3 | `NOTICE_LATE` | `notice_lag >= 13 and held_age >= 34` | 核对通知回执 |

第一条为暂停规则。其余命中与模型阈值 `34` 共同决定是否列入候选。单据所需工位数按 `1 + int(waiting_readers < 3)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 留架回访安排

示例馆周一闭馆，其他日期每日 10–19 点开放。到期和回访均落在开馆时间，延期、送达延迟和后续顺位保留在复核联。单据表示当日中午快照。 在派发环节展开现场安排，或从关联单据回查实际读数。
